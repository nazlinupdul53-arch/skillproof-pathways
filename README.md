# Skillproof Pathways

Build a complete full-stack web application called SkillProof for Track 1: Credential Recognition & Skills Validation.

The platform helps migrants and internationally qualified professionals organise academic credentials, demonstrate practical skills, and identify qualification recognition and bridging course requirements.

Include:

Secure user registration and login.

Personal user dashboard and profile.

Qualification submission with document uploads.

Skills assessment and competency profiles.

Credential application status tracking.

Bridging and re-certification course recommendations.

Admin dashboard to review submissions and update statuses.

Implement a functional backend, database, authentication, secure document storage and connected frontend. Use realistic demo data and make all core features operational.

Design: modern, professional, responsive interface using navy blue, teal and white.

Important: Clearly distinguish platform document review from official qualification verification. Do not claim official recognition.
